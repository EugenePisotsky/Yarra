1280 × 720 · MSAA off · 1.5 mm ray bias. All compared colors use the same maximum direct-light reduction. Physical view opening is disabled so the caster remains identical across cameras. Wind poses are 0, 1/60, 0.5 and 1 s; playback cycles discrete captures, not a real-time simulation.

Same production blade material functions and exposure; linear output is encoded to sRGB without the game tonemapper. No world CSM, terrain texture, AO replacement, filtering or temporal history. The approximation uses captured world positions as a convenient depth reconstruction; a runtime pass would need grass-inclusive depth and reconstruction. These captures do not measure runtime cost.
